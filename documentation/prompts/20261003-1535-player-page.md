# Player Page Feature

## Goal
Build a public player profile page at `/club/:club_id/player/:player_id` showing season stats, game-by-game breakdown, and related articles. Also refactor the Team page to use a shared `PageHero` component.

## Endpoints added (PlayerController)

- `GET /players/:id` — profile: name, initials, club, teams, detected season
- `GET /players/:id/stats` — stat strip data: games played/total, starters, 5 stat avgs with min/max game refs
- `GET /players/:id/games` — per-game rows: date, opponent, badge, won, starter, pts, 3pts, shots, ft, fouls
- `GET /players/:id/news` — articles: games with `blog_title IS NOT NULL`, ordered date DESC

Season is auto-detected as the most recent season from the player's `PlayerStatRow → game → group → championship` chain. `detectSeason` is a private helper reused by all four methods.

`won` is computed by comparing the player's club side score. `opponent` is the other team (not the player's club). `championship_badge` uses `short_code ?? name`.

## Frontend components

- `PageHero` (shared) — dark banner with avatar, title, subtitle (ReactNode), breadcrumbs, season pill, stat strip slot. Applied to Player page and Team page.
- `PlayerStatStrip` — 6-cell strip: Matchs joués (blue, with /total and starters), then Pts/3pts/Tirs/LF/Fautes moy. with min/max anchor links. Min/max hidden when only 1 game.
- `PlayerGamesTable` — section header + white card table, 9 cols. Starter dot, V/D badge, pts bold, row click navigates to game.
- `PlayerNewsSidebar` — section header + card list, date + badge + 2-line-clamped title, links to game page.
- `Player.tsx` — fetches all 4 endpoints in parallel. Two-col grid layout (`1fr 320px`).

## Key decisions
- Route is nested under Club: `/club/:club_id/player/:player_id`
- Games count denominator: total games for all teams the player appeared for in the season (no double-count)
- Hero subtitle: club name + team labels as links to `/teams/:id`
- Dark hero: `bg-[#31302e] dark:bg-[#111110]`
- Player links added in Team page (TOTALS + AVERAGES tables) and `PlayerTable` component on the Game page
- `Game` entity injected into `PlayerModule` via `TypeOrmModule.forFeature`
